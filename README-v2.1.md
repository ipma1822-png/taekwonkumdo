# 세계태권검도연맹 홈페이지 v2.1

v2.0의 기존 내용과 기존 페이지는 그대로 유지한 상태에서 메뉴 및 공식 로고를 수정했습니다.

## v2.1 수정
- 상단 브랜드 마크를 첨부된 WTKF 공식 원형 로고로 교체
- 메인 움직이는 원형 중심부에도 WTKF 공식 로고 적용
- '모든 메뉴에 마우스를 올리면 같은 메가메뉴가 보이던 현상' 제거
- 메뉴별 개별 하위메뉴 구현
  - 연맹소개
  - 철학
  - 프로그램
  - 임원·지도자
  - 지부
  - 조회
  - 자료실
  - 미디어
  - 신청·문의
- 모바일에서도 각 메뉴를 클릭하면 해당 메뉴의 하위메뉴만 펼쳐지도록 수정
- 첨부된 WTKF 심볼 이미지를 메인 브랜드 소개 영역에 추가
- 기존 v2.0 및 이전 홈페이지 내용/페이지 보존
- CSS/JS 캐시버전 v2.1 적용

## 업로드
ZIP 압축을 풀고 기존 GitHub 저장소의 파일들을 같은 구조로 교체/업로드하면 됩니다.
assets/img 폴더까지 반드시 함께 업로드해야 공식 로고가 표시됩니다.
